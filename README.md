# PROSTO CRM

Простая CRM для общения с клиентами: переписка из WhatsApp и Instagram в одном окне, карточка клиента и каталог товаров, которые можно сразу предложить в чате.

## Что уже есть

- Веб-версия на Flutter (тот же код потом соберётся для Android и iOS).
- Общий список чатов с фильтрами «Все», «Мои», «Новые» и поиском по имени или номеру.
- Переписка с быстрыми ответами и кнопкой «Взять себе». Кто первым ответил новому клиенту, тот становится ответственным, а статус меняется на «В работе».
- Правило Meta про 24 часа: если клиент писал больше суток назад, поле ответа закрыто.
- Каталог товаров с поиском, фото, ценой и наличием. Кнопка «Предложить» отправляет товар в чат.
- Карточка клиента: статус (Новый, В работе, Купил, Отказ), ответственный, заметка.
- Загрузка товаров из Excel по шаблону [`templates/товары_шаблон.xlsx`](templates/товары_шаблон.xlsx). Повторная загрузка обновляет товары по артикулу.

Сейчас данные демонстрационные и хранятся в памяти браузера. Дальше по плану: Firebase (вход сотрудников, база, push-уведомления) и подключение настоящих WhatsApp и Instagram через API Meta.

## Как запустить

Нужен [Flutter](https://docs.flutter.dev/get-started/install) 3.47 или новее.

```bash
cd app
flutter pub get
flutter run -d chrome     # открыть в браузере
flutter test              # тесты
flutter build web         # собрать сайт в app/build/web
```

## Устройство кода

| Путь | Что там |
| --- | --- |
| `app/lib/models.dart` | Клиент, сообщение, товар, сотрудник, статусы |
| `app/lib/data/crm_store.dart` | Все данные и правила: ответы, назначение, 24 часа, импорт |
| `app/lib/data/product_import.dart` | Чтение товаров из Excel |
| `app/lib/ui/` | Экраны: вход, список чатов, переписка, товары и карточка клиента |
| `app/test/` | Тесты |
